Prepared request and output schemas use JSON Schema2020-12. They describe
strict object shapes, operation-specific fields, nullable unknown coverage,
canonical decimal generations (including the signed-counter ceiling), exact
receipt structures, and error/known-receipt envelopes. They do not replace
storage transition/binding validation. UTF-8 byte limits, nonzero vector norms,
time ordering and lexical integer tokens remain parser checks; JSON Schema's
integer type describes a numeric value rather than the original token spelling.
The schema is not added to live contract1 discovery.
