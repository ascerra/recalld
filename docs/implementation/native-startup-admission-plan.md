# Native startup admission: dependency plan, not implementation

Owner Feynman for ordinary owning engine/system/daemon startup; Huygens owns
public routing/capabilities. This plan records the seam found in source, not a
claim that all required dependencies are already validated or joined.

Required frozen parents, to be resolved to exact published commits before code:

1. Native purge on actual corrected98 +94, then the minimal shared-history join
   with corrected101 (runtime4ad7965) and validated97 keyed no-change proof.
   Retired namespace identity/dimension/profile, per-origin policy ordering,
   ledger and physical edge reverse history must validate together.
2. Actual catalog/policy/purge and graph/store/batch producer consumers, native
   observation/readers and maintenance/sweep. Each configured writer either
   participates through its actual canonical proof/outbox or rejects explicitly
   before fresh work. An accepted tracker ticket alone is not writer proof.
3. Halley's actual publication/read boundary and public consumers. Whole query
   namespace/policy/records/cache/graph/vector/FTS/entity agreement must use actual
   GenerationRef, including metadata-only and lifecycle writes. Exact-vector
   capture and effects_epoch alone do not close this gate.

Choose the smallest actual closure parent after these joins are frozen; name
additional prerequisites explicitly. No broad validation checkpoint as a
shipping dependency. Run an isolated checkpoint first if composition needs it;
ship any required production glue in a minimal reviewable join.

Existing API seams:

- RedbStorageEngine::open -> open_mode currently owns StoreOwnership and the
  directory lock before disposable-copy preflight and writable opens. Reuse
  this one constructor/recovery sequence. The private open_native entry is
  evidence of existing native recovery, not a second serving engine.
- Validate control/schema/lineage, complete known canonical inventory, selected
  text fence/payload, vector ownership, edge/proof history and exact pending
  effects/purge on disposable copies under both ownership guards. Repair only
  copies during inspection; malformed originals remain byte-identical. Do not
  initialize missing native tables, advance lineage or rewrite old receipts.
- After admission, open existing metadata in native guarded mode, recover exact
  pending effects/purge, validate canonical ownership before cleanup, construct
  actual derived components, then publish their current GenerationRef through
  the sole registry. Preserve native restrictions on raw legacy mutation APIs.
- Recalld::with_clock continues to use the owning engine and existing startup
  builder. No new NativeSession service facade, registry or background engine.
  Daemon readiness/socket acceptance must follow successful startup publication.
  Huygens owns route and profile/capability selection; do not remove embedding
  or transport gates independently of those consumers.

Required actual tests on final composed source:

- Ordinary engine/system/daemon open and restart a fully validated native store;
  use synthetic profiles/providers and roots. No provider call or clock-derived
  observation is invented merely by opening. Existing legacy startup remains.
- Before/after metadata commit process exits for participating writers and
  pending purge, followed by ordinary startup recovery and original-key replay;
  exactly one logical mutation, full preserved receipts and current publication.
- Malformed repaired-copy control/ledger/effects/progress/bindings/text/vector/
  edge histories reject before writable originals change, with both ownership
  locks held. Unknown required versions and historical read-only lineages fail
  closed. Ordinary offline abort-on-repair behavior stays separate.
- Actual component publication failure cannot make the daemon/query ready or
  return a false empty result. Reopen/retry reconstructs the same canonical G.
- Closed admission/worker cancellation retains accepted descendant ownership;
  no sync lock crosses await. Reuse graph -> storage order and worker-held
  publication leases, preserving unknown outcome tracking.
- Public route tests cover catalog/policy-only G changes, native observations,
  graph no-op receipt G, purge and batch, including explicit unsupported paths.
  Test real query/get/similar consistency on the joined reader implementation.

This work cannot start by simply changing open_mode(false) to true or deleting
schema errors. Exact dependency hashes and reviewed seam changes are required
before startup implementation. Until then ordinary native serving stays gated.

## API compatibility prerequisite, 2026-11-14

versions and both disk schemas. Record the actual canonical adapter, unchanged
API1 payload/default behavior, and any explicit unsupported contract per row.

a hidden legacy-writer failure is not compatibility. Lifecycle defaults remain
separate and unchanged. Huygens owns these wire adapters; Feynman owns the
existing constructor/recovery admission. The matrix and exact source refs must
be reconciled before startup code, not inferred from a successful native open.
