## Producer and units

Counters contain no IDs or query/namespace/tag/label values. These are not physical redb rows/bytes/lookups, skipped upstream namespace-index entries, projection work or a new corpus-wide cost measurement.

One reason-returning predicate implementation replaces the existing boolean implementation; existing callers retain boolean wrappers. The original short-circuit order remains namespace, tombstone, ghost, phase, strength, permastore, structured labels, required tags, excluded tags. Comparisons and compiled/fallback label behavior stay unchanged. The record-only predicate still excludes tombstones. No second predicate evaluation, canonical read, score computation, clock/policy pin, ranking formula or candidate cap is introduced. Enumeration/projection and subsequent eligible-record validation errors still fail the operation before observation; there is no measured empty-success fallback.

`passed` counts rows before collection into the existing eligible UUID map. The map continues to determine distinct eligible candidates, so duplicate rows in a controlled adapter can produce passed greater than unique eligible. Each presented row contributes once to passed or one rejection count. Production canonical storage identity guarantees are unchanged. A controlled wrong-namespace/tombstone row counts only its first namespace rejection. Production namespace enumeration can skip missing records upstream; those unseen entries are not counted here.

Only requested MetadataOnly retrieval copies these facts into the Metadata channel's examined count/unit. Its eligible/offered/admitted/cap fields retain the existing unique-candidate meaning. Hybrid/vector/entity queries carry shared canonical-loop facts but keep Metadata `NotRequested` and its measurements unknown. V1 diagnostics remain absent; separate similarity selection does not fabricate this ranked-query loop measurement. Unknown source adapters retain unknown coverage. Huygens has the typed unit/fields for a later actual wire consumer; this child activates no public selector or explain option.
