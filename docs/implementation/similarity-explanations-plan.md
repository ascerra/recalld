Do not reuse `ScoreExplanation`, synthesize a baseline-v1 decomposition, invent temporal/entity/RIF factors, or serialize null as complete evidence. Keep this Rust-only producer separate from Huygens's prepared public parser/schema/serializer; public `explain:true` remains explicitly unsupported until his actual consumer joins the validated typed producer and transport tests. No automatic serving activation or default change.

Proposed per-row evidence: algorithm discriminator for cosine/max inheritance, own cosine and minScore admission disposition, independently admitted own score (optional), inherited floor (optional), bounded eligible predecessor contributions `{origin_id, cosine}`, exact omitted-origin count, final similarity, and current/history version status where the selected semantics provides it. The selected response already supplies read generation, evaluated clock and per-namespace lifecycle facts once; do not resample or duplicate them per donor. Retain original source ID/namespace/profile at the response boundary only from the existing canonical admission proof, not a second resolver/provider call. Wire field names and algorithm discriminator are coordinated with Huygens before serialization.

Its explanation must show the actual rejected own cosine/disposition separately from its admitted inherited floor; rejected own evidence never adds an exposure channel or changes selection. Missing independently scored own evidence remains absent and explicitly unadmitted; never label a predecessor's cosine as the terminal's cosine. No additional dot product or changed threshold comparison is needed.

Capture a donor contribution only after that origin passes canonical hard eligibility and score admission and its same-scope supersession path has actually resolved to an eligible terminal. For history mode the original row retains its own score/status; do not fabricate current inheritance. Preserve the exact existing `max(own, inherited)` operation, no sum, no second multiplier, and existing score/UUID ties. Final evidence is attached only to IDs that survived result truncation and actual hydration. Existing final canonical/scope validation and observer order remain unchanged.

The 64 display limit is not a cap on examined records, chains, aggregate candidate allocation or latency; A5 measurement remains required before performance claims.
