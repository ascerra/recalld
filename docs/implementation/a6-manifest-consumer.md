# Manifest-consuming internal diagnostic

Manifest foundation: frozen PR75 `8ecdd5a`, PR84 runtime `6ce05ab` / seal `586f02e`; no public-runner, tracker or coherent-core ancestry is imported. This is the independently named `manifest-internal-diagnostic-v2` track. It consumes the real canonical insertion/startup and QueryEngine paths already used by PR75. It is not the A6 public actor, an upstream dataset adapter/scorer implementation, a semantic-quality result, or deterministic canonical reset.

`scripts/offline-evaluation.py` creates an immutable `manifest.json`, `actor-inputs.json` and evaluator-only `evaluator-labels.json` from its explicit synthetic arguments and actual source/image hashes. The mutable supervisor status/output hashes move to `diagnostic-run.json`: the input manifest never hashes itself. Synthetic revision means the SHA-256 of the actual actor artifact, not an invented upstream revision. External datasets, licenses, model revisions and tokenizers are not used or inferred. All units belong to one declared regression group, with no training/split claim.

The actual example requires `--manifest PATH --out NEW_DIRECTORY`. CLI corpus overrides are removed so the validated plan is authoritative. It validates all input fields and files before creating the output directory or store. Unknown/unsupported versions and fields, unsupported public-v2/barrier/reset/snapshot/clock-advance/deterministic-ID/RNG requirements, mismatched source or artifact hashes (including exact source-map/commit/patch/image identity embedded by the actual supervisor build), injected actor labels and invalid source/evidence references fail closed. The supervisor validates numeric plan arguments before creating scratch. Supervisor preparation artifacts are distinct from executing an episode.

Run the real supervisor from this checkout:

```sh
python3 scripts/offline-evaluation.py --track manifest-internal-diagnostic-v2 \
  --cache /tmp/recalld-PRIOR-SCRATCH/cargo \
  --build-cache /tmp/recalld-PRIOR-SCRATCH/target \
  --records 100 --dimensions 16 --k 5 --warmup 1 --samples 4 --runs 3 --seed 7
```

The explicit `--track` flag is mandatory; an old supervisor invocation fails before creating scratch. It copies registry/dependency caches to a fresh private target, snapshots only allowlisted source, and uses the pinned existing image with network disabled, 2 CPUs, 4 GiB, an isolated home and no credential/socket mounts. The Rust example consumes the same manifest in all three fresh processes. Old studies retain their historical scripts/source hashes; an old direct example invocation fails rather than silently measuring this new track. Do not rewrite historical reports or compare their timing results as equivalent measurements.

The manifest pins independent harness versions at 1 and the actual **legacy internal** runtime selection: contract/retrieval/control/record versions 1, `canonicalSchemaVersion: null` with `canonicalRepresentation: "legacy-schema-none"` (actual `DiskRecord.schema == None`), receipt/request-hash 1, legacy lifecycle, baseline ranking, RIF off. `backupFormatVersion` and `exportFormatVersion` are explicitly null with `offlineFormats: "not-used-or-advertised-by-this-track"`; this diagnostic invokes neither operation. Requesting their integrated formats fails closed rather than claiming them. Derived implementations are pinned by actual source hashes, not invented format numbers. Native/public-v2 and coherent controls remain unavailable. A fixed lifecycle ManualClock and seeded synthetic vector generator do not control random store/operation UUIDs. Real receipts and all semantic differences remain retained without new identity normalization.

`source-mappings.jsonl` appends only after each successful canonical insertion and maps actual committed memory UUIDs to complete synthetic source identities, ordinal, role, source timestamp, content hash, transformation and artifact revision. The evaluator source ledger emits seen/attempted/accepted or rejection events; the original raw fixture, record/control snapshots, replay results and receipt ledger remain intact. Schema-bearing records are not synthesized. Query source metrics use the validated evaluator sidecar and the UUID mapping, not an implicit UUID-to-label scoring shortcut. These metrics describe synthetic evidence units only, never upstream dataset/scorer semantics or proposition preservation.

`trace.jsonl` contains version1 actor-side action/outcome records, including warmups, full insertion receipts and an expected failed query. Evaluator metrics and historical diagnostic traces live under `evaluator/`. `readGeneration` is null and readiness explicitly unavailable; no metadata generation is substituted for a coherent read view. Tokens, snapshots, models and reward are unavailable, not fabricated. `actor-replay-cache.json` contains only actor-query vectors. The provider receives a typed profile/environment projection, never the evaluator-bearing manifest object. Its key binds the complete query text, namespace, role, profile/prompt/tokenizer state and frozen environment hash. A missing entry errors through the actual QueryEngine; no live/generative fallback exists.

The exact config/manifest/trace interface is confined to `examples/support/evaluation_manifest.rs`, consumed by `examples/offline_eval.rs`; it adds no production owner or schema framework. Halley owns future coherent-core/barrier/reset/clock/RNG capabilities. Enabling one requires actual integration and a revised supported manifest capability contract, not toggling a claim in the output.

The v2 internal track adds `scoring.profile: synthetic-unique-source-v1`, consumed by the actual evaluator. The independent manifest/source-mapping/trace versions remain 1, legacy canonical schema remains absent, and public/coherent/reset capabilities remain unavailable. V1 invocations/manifests are rejected by this checkout; reproduce the frozen v1 study at PR84 `586f02e`.

Missing query annotations are `unknown`; present empty labels are `zero_label`/unscored. Neither enters metric denominators. For annotated queries, map committed UUIDs to supporting source IDs, deduplicate at first occurrence before cutoffs, then compute Recall@5/10/20, binary-source nDCG@10 and all-required over the complete returned unique-source list. These are binary synthetic units, never official BEIR or upstream answer metrics. Returned depth is the explicit plan k; a requested cutoff above that depth does not invent additional candidates.

`evaluator/scoring-summary.json` counts measured query events (both internal engine cells, excluding warmups), separately publishes scored/zero/unknown counts, and averages only scored events. This is not an independent-query statistical estimate. `evaluator/trace.jsonl` records query ID and actual mapped result sources for an independent verifier. Retention uses successful commit mappings, never planned insertions.

`evaluator/turn-coverage.json` consumes append-only source events and counts seen/attempted/accepted/no_op/rejected/truncated, pending and unseen with explicit decimal counters and coverage denominators. It is also emitted on insertion rejection. The raw-unit runner produces accepted events on success; no_op/truncated accounting is exercised by hand-written ledger goldens, not claimed as an extraction runtime. Original receipt ledger remains intact.
