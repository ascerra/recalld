- Native catalog uses original unkeyed API1 context; no forced ctx2, keyed replay reinterpretation or new engine. Existing v2 replay/hash controls remain exercised.
- An opaque, crate-controlled descriptor carries actual MCP ID/era/timezone or the HTTP surface. Native application policy is8,388,608 encoded bytes, not a claimed daemon negotiation: final local stdio JSON plus LF, or HTTP JSON body excluding headers/framing. Exact serializers are counted before canonical commit; candidate refusal does not record a candidate as committed.
- Impossible outer-envelope admission rejects before provider/clock/IDs/accepted work. A later candidate refusal may consume one owned clock/operation-ID draw but rolls back key/G/counter/files. An already oversized echoed request ID cannot itself be promised a bounded rejection frame. Legacy request acceptance is unchanged.
- Returned Ok/known-error receipt or actual unknown operation ID enters the existing collector inside the blocking worker before its fallible tail. Worker-held publication lease survives caller cancellation. Completion follows lock release with the same accepted-work scope and admitted evidence; foreign pending work is rejected, not silently drained.
- Unknown takes precedence while retaining separately known full receipt evidence. Only an actually returned Unknown(Some(id)) supplies an unknown-operation ID; no readback, invented ID, fake CommitError or receipt reference. Generic committed failures use truthful SERVICE_UNAVAILABLE without asserting derived readiness.
- Invalid internal snapshots remain fully typed to the endpoint, which logs the cause and emits bounded INTERNAL_ERROR/unknown without fabricated receipts/IDs/readiness. Synthetic corruption tests cover multiple/conflicting/unadmitted evidence. The alternate projector defensively rejects the same invalid state; current API1 does not route through it.
