# Legacy online ingestion diagnostic

Parent: PR #75, `8ecdd5a4b20c1f1555b98c84bd0771625e51c67d`. This is a bounded diagnostic, not an optimization or promotion experiment. No native, batch, producer, RIF, or sampling parent is imported. Legacy serving remains unchanged. Instrumentation is opt-in using the existing `recalld::performance=trace` target; the previous full-tracing overhead gate failed.

Six sequential, independent fresh-store cells, each one warmup plus three measured successful writes (retain every error, timeout and partial file; no retries):

| Cell | Actual consumer | Initial records | Extra legacy exposure receipts | Initial canonical edges |
| --- | --- | ---: | ---: | ---: |
| adapter100 | Typed McpStorageAdapter with explicit vectors; not MCP wire | 100 | 0 | 0 |
| mcp100 | Actual MCP tool dispatcher, deterministic local embedding provider | 100 | 0 | 0 |
| daemon100 | Actual DaemonClient/DaemonServer Unix-socket RPC, explicit vectors | 100 | 0 | 0 |
| daemon1000 | Same daemon RPC | 1000 | 0 | 0 |
| history1000 | Same daemon RPC | 100 | 1000 | 0 |
| edges99 | Same daemon RPC | 100 | 0 | 99 |

Fixed d384 unit vector, injected lifecycle clock 1767225600000 ms, one legacy namespace, serial writes, duplicate advisory disabled, graph autolink and decay sweep disabled. Canonical setup uses actual InsertMemory writes, parent links and legacy record_exposures receipts, followed by actual production startup/completion. Setup is excluded from write windows. The history cell does **not** measure native creation-history scans. Neither provider latency over a network nor ordinary native serving is measured.

The MCP path invokes the actual tool argument parser/handler and result serialization in-process. It does not measure stdio JSON-RPC framing or an external MCP client. Its input has no embedding wire field. The deterministic provider returns one unit vector with no network/cache/retry. The adapter control is explicitly not MCP wire. The daemon client and server share the probe process but communicate through the real Unix socket, frame encoding/decoding and RPC dispatcher. No client parallelism or process-start latency is measured.

Each acknowledgment timer starts immediately before the actual call (including probe argument/result conversion) and ends on returned result. A separate observation includes the final trace sink flush. Persist individual monotonic durations plus realtime start/ack/end timestamps for syscall attribution. Realtime clocks only correlate traces, never define latency. Post-response checks assert one new committed generation, canonical presence and vector/graph/FTS/entity publication, then actual admitted read-only get. These checks are outside the write window. A cell fails on any check, unexpected provider calls or trace I/O error. Success responses and actual serialized errors are preserved; no fabricated wire receipt is added. Canonical receipt identities emitted by the existing internal receipt helper remain isolated trace fields.

Existing Timer/Timeline/Worker/Hold provide store phases, provider duration, blocking worker queue delay, storage wait/hold, publication and graph/index waits, canonical record/edge scans, combined record-view rebuild, edge rebuild/publication, invalidation and actual effects acknowledgment. Counters report loaded records/live records/edges/pending effects and no-op completion. Record-view time includes vector/text reads, FTS work and entity work; these are not independently timed per record. Timelines partition only their own request; nested durations must not be summed into wall time. Sink emission cost remains inside the next interval/residual or enclosing duration. Arbitrary subscriber panic is not contained.

Run the release binary under `strace -f -ttt -T -y -e trace=fsync,fdatasync,msync`, preserving all thread/child events, unfinished/resumed calls, return codes and exit/signal records. Attribute sync calls by start/end containment in each write's realtime [begin,ack] window, retain boundary/unknown attribution, report each OS TID and file class. Syscall elapsed time includes scheduling/trace overhead, is not CPU time, and can overlap other durations. This does not prove power-loss durability. All setup/verification/shutdown sync calls remain in the raw log outside measured windows. No untraced speed claim follows: both full event emission and ptrace perturb timing.

Runtime: offline Docker (`--network none --cpus 2 --memory 4g`), two Tokio workers, no home/credentials/host-socket mounts. Diagnostic image adds only strace to recalld-ci:1.94 via separately authorized package fetch; record image ID, strace/Rust versions and binary/source hashes. No privileged container or extra ptrace capability is needed. One own container at a time, 180-second timeout per cell, stop the study on first failure; no extended/exclusive host window. Capture privacy-limited host/container resource snapshots around each cell. Others may build; this is shared-host characterization. Retain individual write durations and ranges only: three measured writes per cell cannot establish p95, confidence intervals, steady throughput, scaling laws or promotion. Process high-water RSS includes setup.

Before tests/build: immutable allowlisted source snapshot/hash manifest, read-only source mount, private Cargo/target and package clean after source switching. Verify source hashes after build and again after measurement; retain failed preparations/builds. After the six cells: stream event/syscall QA, check four store roots, four rebuilt and four no-op completions, exact record/edge counters, provider counts, canonical receipt identities, timeline accounting and absence of payload-bearing event fields. Missing/inconsistent evidence invalidates conclusions. Preserve raw evidence outside Git with SHA manifests and verified HOME work-notes copy; commit only source, protocol, compact QA/report/manifests.
