# Native prefix checkpoint diagnostic

The named track `serialized-native-prefix-synthetic-diagnostic-v1` opens a strictly validated existing schema2 prefix through the shared owned initializer. It uses actual API1 MCP `get_memory` and `recall_memories`, only with explicit `recordAccess:false`. Missing or true access intent and all writer calls fail before dispatch. This private fixture constructor does not activate ordinary native startup or public API2.

The fixture builder uses real legacy insertion and migration to establish four synthetic source records, exact mappings and migration receipts. These are acknowledged prefix inputs, not live actor ingestion or independently deterministic native genesis. All namespaces require compatible Bound profiles. Wrong model, unknown provenance and revision mismatch fail before provider calls. The actor receives only its current action and public stdio; labels, future schedule and inherited control pipes remain evaluator-only.

The manifest independently pins manifest/source-mapping/trace versions1, public contract1, native canonical schema2, checkpoint/control versions1, actual source and executable hashes, the synthetic provider/profile and replay cache. Automatic sweep, autolink and RIF are disabled; query cache misses fail closed. The lifecycle clock and canonical allocator are owned, but this does not claim all RNGs, startup lineage, response ReadViews or full A6 are controlled. The native logical hash uses the existing typed canonical walker without export-envelope normalization.

Use immutable source and one private Cargo/target with the existing registry read-only. All builds and runs use the pinned Rust image, network none,2CPU/4GiB and one build job. `build.json` must contain the actual source commit/files and image ID, matching the compiled `RECALLD_A6_SOURCE_COMMIT`, `RECALLD_A6_SOURCE_TREE_SHA256` and `RECALLD_A6_IMAGE_ID`. The source-tree digest is SHA256 of the runner's sorted, indented JSON encoding plus newline. Do not substitute a moving worktree or inherited executable.

```sh
cargo build --offline --locked -j1 --features bench --example owned_evaluator --example native_prefix_fixture --example score_mcp_episode
python3 scripts/public-mcp-evaluation.py prepare --track serialized-native-prefix-synthetic-diagnostic-v1 --binary /target/debug/examples/owned_evaluator --scorer /target/debug/examples/score_mcp_episode --build /output/build.json --out /output/inputs

```

The actual runner compares baseline and three fresh-process restores: public outputs/order/exposed scores, provider inputs/vectors, canonical generation/hash, clock and allocation cursor. It also executes label/future-query canaries with distinct manifest/cache identities, replay misses, namespace rejection, blocked-query worker exclusion, source/destination/digest protections, unsupported checkpoint-clock rejection and profile negatives. Reports are saved before assertions, and no failed control/action is retried. Source/checkpoint byte canaries supplement the typed logical hash; they are not another hash format.
